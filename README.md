# 💚 FinWise — Finance Management Mobile App

FinWise is a mobile application designed to help users manage their personal finances, track income and expenses, and monitor transactions.

This project was developed using React Native and Expo as part of a mobile application development course.

## 📱 Features

- Splash Screen
- Onboarding Screens
- Login Screen
- Registration Screen
- Forgot Password Screen
- Security PIN Screen
- New Password Screen
- Fingerprint Screen
- Home Dashboard
- Notifications Screen
- Transactions History
- User Profile

## 🛠 Technologies Used

- React Native
- Expo
- JavaScript
- TypeScript
- Expo Router
- React Hooks
- Git
- GitHub

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/aseidrazakh-cmd/FinWise.git
```

Navigate to the project directory:

```bash
cd FinWise
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npx expo start --web
```
